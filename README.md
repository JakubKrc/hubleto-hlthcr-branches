# Hlthcr Branches

Branches of the clients, job positions with hazard categories, categorisation of work, deficiencies.

Hubleto app of the Hlthcr set (occupational health service, Slovakia). Namespace: `Hubleto\App\External\WaiBlue\HlthcrBranches`.
Needs: `wai-blue/hubleto-hlthcr-core`.

## Install into a Hubleto project

```bash
composer config repositories.wai-blue/hubleto-hlthcr-branches vcs <repository-url>
composer require wai-blue/hubleto-hlthcr-branches:dev-main
php hubleto app install "Hubleto\App\External\WaiBlue\HlthcrBranches"
npm run build
```
